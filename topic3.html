📝 Pipeline Hazards (Overview & Structural) Topic 3

The 1-Sentence Story: Pipeline hazards are situations that prevent the next instruction from executing in the following clock cycle, causing stalls; they are classified into structural, data, and control hazards, with structural hazards resolved by duplicating hardware resources.

📌 Definitions & Key Terms

Hazard
Any condition that causes the pipeline to stall, reducing throughput and speedup.
Stall (Bubble)
An idle clock cycle inserted into the pipeline because an instruction cannot proceed.
Structural Hazard
A resource conflict where two or more instructions need the same hardware resource at the same time.

🔀 The Three Types of Hazards

🧱

Structural Hazards

Cause

Resource conflict (e.g., shared memory, single ALU in superscalar, limited register ports).

Common Example

The Fetch stage needs to read an instruction from memory, while the Memory stage needs to read/write data. If there is only one memory unit, they conflict.

Solution — Duplicate Resources
  • Separate Instruction Cache (I-cache) and Data Cache (D-cache) — Harvard Architecture.
  • Multiple ALUs (for superscalar processors).
  • More register file ports.
✔ resolved by adding hardware
🔗

Data Hazards

Cause

An instruction depends on the result of a previous instruction that has not yet completed.

Example
I1: MUL R2, R3, R4
I2: ADD R5, R4, R6  // needs new R4 from I1
Solutions
  • Operand forwarding (bypassing).
  • Compiler scheduling.
  • Stalling (NOP insertion).
📖 covered in detail in Topic 4
🛤️

Control (Instruction) Hazards

Cause

Branch or jump instructions change the sequence of execution. The pipeline has fetched instructions from the wrong path.

Example
BEQZ R2, NEXT  // decision known only at Execute stage
Solutions
  • Branch prediction.
  • Delayed branching.
  • Speculative execution.
📖 covered in detail in Topic 5
📌 KEY EXAM POINTS
Hazards cause the pipeline to stall, creating bubbles (idle cycles).
Structural hazards are resolved by adding hardware (duplicating resources).
Most common structural hazard solution: separate instruction and data memories (Harvard architecture).
In a basic 5-stage pipeline, the main structural hazard is the memory conflict between Fetch and Memory stages.
