📝 Basic Concepts of Pipelining Topic 1

The 1-Sentence Story: Pipelining is a technique that overlaps the execution of multiple instructions by dividing instruction processing into distinct stages, allowing different hardware units to work on different instructions simultaneously to increase throughput.

📌 Definitions & Key Terms

Pipelining
A technique where multiple instructions are overlapped in execution by dividing the instruction cycle into distinct stages, each handled by a dedicated hardware unit.
Throughput
The number of instructions completed per unit of time. (Pipelining increases throughput).
Latency
The time taken to complete a single instruction. (Pipelining does NOT reduce latency).
Interstage Buffer
A clocked buffer placed between pipeline stages to hold intermediate results and synchronize data flow.

🏭 The Core Idea (Assembly Line Analogy)

🔹 Overlapping Execution

  • Just as a car assembly line has stations (chassis, body, engine) working on different cars simultaneously, a pipelined processor has stages (Fetch, Decode, Execute, Write-back) working on different instructions simultaneously.
  • A new instruction completes every clock cycle after the pipeline is full.

🔹 Two-Stage Pipeline

IFU → B₁ → EU

IFU Instruction Fetch Unit

Fetches the instruction from memory.

B₁ Buffer

Stores the fetched instruction while the EU processes the previous one.

EU Execution Unit

Executes the fetched instruction.

  • Fetch and Execute operate in parallel.

🔹 Four-Stage Pipeline (F, D, E, W)

F → D → E → W

F Fetch

Read instruction from memory.

D Decode

Decode instruction and fetch operands.

E Execute

Perform the operation (ALU).

W Write-back

Store the result to the register file.

  • At any time, 4 instructions are in different stages.
  • One instruction completes per clock cycle after the pipeline is full.

🧩 Interstage Buffers (Data Flow)

Buffer Stage Transition Contents
B₁ F → D Holds the fetched instruction.
B₂ D → E Holds decoded operands and operation information.
B₃ E → W Holds the result and destination register information.

🔹 Why Needed?

  • To synchronize stages.
  • Hold intermediate data.
  • Prevent a faster stage from overwriting data a slower stage hasn't consumed yet.

⚡ Role of Cache Memory in Pipelining

🔹 The Bottleneck Problem

  • Each stage should complete in one clock cycle.
  • Main memory is too slow for instruction fetches, which would bottleneck the pipeline.
  • Solution: Use on-chip cache memory.
✔ Faster instruction access.
✔ Uniform stage duration (all stages take roughly equal time).
✔ Shorter clock cycles.
📌 KEY EXAM POINT
Pipelining improves throughput, not latency.
Clock period must accommodate the slowest pipeline stage.
Without cache, the Fetch stage would be bottlenecked by slow main memory, making pipelining ineffective.
