📝 Pipeline Performance Metrics Topic 2

The 1-Sentence Story: Pipeline performance is measured by throughput (instructions completed per unit time), speedup (ratio of non-pipelined to pipelined time), and efficiency (utilization of pipeline stages), with ideal speedup approaching the number of stages k for large n.

📌 Definitions & Key Terms

Throughput (TP)
Number of instructions completed per unit time. TP = n / Tp.
Latency (L)
Time taken to complete a single instruction. Pipelining does not reduce latency.
Speedup (S)
Ratio of sequential (non-pipelined) time to pipelined time. S = Tn / Tp.
Efficiency (E)
Utilization of all pipeline stages. E = S / k.

🧮 Key Formulas

🔹 Non-Pipelined Time

Tn Tn = n × tn

🔹 Pipelined Time (k stages)

Tp Tp = [ k + (n − 1) ] × tp k = number of stages  ·  n = number of instructions  ·  tp = clock period per stage
  • The first instruction takes k cycles to fill the pipeline.
  • Each subsequent instruction takes 1 additional cycle.

🔹 Speedup

S S = Tn / Tp = [ n × tn ] / [ (k + (n − 1)) × tp ]

🔹 Ideal Speedup (assuming tn = k × tp)

S ideal S = n·k / (k + n − 1) For large n: S ≈ k (speedup approaches the number of stages).

🔹 Efficiency

E E = S / k = n / (k + n − 1) For large n: E → 1 (100% utilization).

⚖️ Ideal vs. Real Speedup

✨ Ideal Speedup

  • S = k
  • Achieved only if all stages take equal time.
  • And there are no hazards.

⚠️ Real Speedup

  • S < k
  • Due to pipeline hazards (structural, data, control).
  • Stage imbalance (faster stages wait for the slowest stage).
  • Pipeline fill/drain time.
  • Overhead (clock skew, buffer delays).
📌 KEY EXAM POINTS
Pipelining improves throughput, not latency.
Maximum speedup = number of stages k.
Real speedup is always less than ideal due to hazards and stage imbalance.
Efficiency tells you what percentage of the pipeline is actually doing useful work.
