📝 Multiprocessors & Multi-Core Systems Topic 7

The 1-Sentence Story: Multiprocessors and multi-core systems achieve higher throughput by executing multiple threads or processes simultaneously, but their performance is limited by shared bus contention, cache coherence, and the serial fraction of programs (Amdahl's Law).

📌 Definitions & Key Terms

SMP
Symmetric Multiprocessor: two or more comparable processors sharing main memory and I/O, managed by an integrated OS.
Multiprogramming
One CPU, several processes interleaved (fake parallelism).
Multiprocessing
Multiple CPUs, processes execute simultaneously (true parallelism).
UMA
Uniform Memory Access: all processors access a single shared memory with approximately equal latency.
NUMA
Non-Uniform Memory Access: memory is distributed; local access is faster than remote access.
Multi-Core Processor
Multiple processor cores integrated on a single silicon die.
Amdahl's Law
Speedup is limited by the serial fraction of a program.

🖥️ SMP Characteristics

🔹 Symmetric Multiprocessor

  • Two or more similar processors.
  • Shared main memory (UMA).
  • Shared I/O resources.
  • Approximately uniform memory access time.
  • Integrated OS coordinates all processors.
  • "Symmetric" means no processor is permanently restricted to special tasks.

🚧 Shared Bus Bottleneck (SMP)

🔹 Bus Contention

  • Only one bus master can control the bus at a time.
  • Adding processors increases bus traffic and contention.
  • Solution: private caches reduce bus traffic (only cache misses require the bus).

⚖️ Multiprogramming vs. Multiprocessing

Feature Multiprogramming Multiprocessing
CPU One CPU Multiple CPUs
Execution Interleaved Simultaneous
Goal Maximize CPU utilization True parallel throughput

🧠 UMA vs. NUMA

Feature UMA NUMA
Memory Single shared memory Distributed memory
Access Time Uniform Local fast, remote slow
Scalability Limited by bus bottleneck Scales better
Example Bus-based SMP Multi-core with distributed L3

🧩 Multi-Core Processors (Why Multicore?)

🔥 Power Consumption Limit

Higher frequency = more heat. Multiple moderate cores are more power-efficient.

P ∝ C·V²·f

📈 Pollack's Rule

Performance ∝ √Complexity. Doubling core complexity yields only ≈41% performance increase. Multiple cores scale better.

⚙️ ILP Limits

Available Instruction-Level Parallelism is limited. Multiple cores provide Thread-Level Parallelism (TLP).

💾 Cache Organizations for Multicores

Private L1: Always private to each core.
Private L2: Dedicated to one core (fast, less contention, but may duplicate data).
Shared L2/L3: Accessible by multiple cores (data reuse, flexible capacity, but contention and higher latency).

📉 Amdahl's Law

Speedup S(N) = 1 / [ (1 − f) + f/N ] f = parallelizable fraction  ·  N = number of cores
Max speedup Smax = 1 / (1 − f)   (as N → ∞)
🔢 Example: 90% parallelizable (f = 0.90), 8 cores:
S(8) = 1 / [0.10 + 0.1125] = 4.71

The serial fraction is the ultimate bottleneck.
📌 KEY EXAM POINTS
SMP = symmetric, shared memory, UMA.
Shared bus = bottleneck as processors increase.
Private caches reduce bus traffic.
Multicore = power-efficient way to increase throughput.
Amdahl's Law limits speedup based on the serial fraction.
MIMD is the Flynn class for SMP and multicore systems.
