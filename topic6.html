📝 Parallel Processors & Flynn's Classification Topic 6

The 1-Sentence Story: Parallel processing improves performance by executing multiple operations simultaneously, and Flynn's taxonomy classifies these systems based on whether they use single or multiple instruction and data streams (SISD, SIMD, MISD, MIMD).

📌 Definitions & Key Terms

Parallel Processing
Execution of concurrent events to achieve faster computational speed.
Decomposition
Partitioning a program or data into independent pieces that can run simultaneously.
Data Parallelism
Same operation applied to different data elements simultaneously.
Task Parallelism
Different operations applied to different data simultaneously.
Instruction Stream
Sequence of instructions read from memory.
Data Stream
Operations performed on the data in the processor.

📶 Levels of Parallelism

LEVEL 1

Job / Program Level

Multiple independent programs running simultaneously.

LEVEL 2

Task / Procedure Level

A single program divided into independent tasks.

LEVEL 3

Inter-Instruction Level

Pipelining and Superscalar execution.

LEVEL 4

Intra-Instruction Level

Micro-operations within a single instruction.

⚡ Why Parallel Processing?

  • Clock speed cannot keep increasing due to power consumption and heat (P ∝ V²f).
  • Multiple moderately clocked cores can offer higher throughput within a power budget.

🔍 Detailed Definitions

SISD

  • Standard von Neumann machine.
  • One operation at a time.
  • Limitation: Von Neumann bottleneck (memory bandwidth limits speed).
Uniprocessor

SIMD

  • One instruction controls many processing elements.
  • Processing elements act in lockstep.
  • Includes vector and array processors.
  • Example: adding corresponding elements of two arrays (C = A + B).
One instruction, many data

MISD

  • Different instruction streams on a common data stream.
  • No commercial implementation (theoretical only).
  • Sometimes used to describe redundant fail-safe systems or pipelined processors.
Theoretical only

MIMD

  • Multiple general-purpose processors.
  • Each executes its own instruction sequence on its own data.
  • Includes SMPs, clusters, NUMA, multi-core processors.
  • Most commercially important class.
Commercially dominant
📌 KEY EXAM POINTS
SISD = Uniprocessor.
SIMD = One instruction, many data (lockstep).
MISD = Theoretical only.
MIMD = General purpose, commercially dominant.
SIMD and MIMD are the most commonly tested classes.
