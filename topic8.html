📝 Cache Coherence Problem & Solutions Topic 8

The 1-Sentence Story: Cache coherence ensures that all processors in a multiprocessor system observe a consistent value for shared memory, solved through software analysis, snoopy protocols (broadcast), directory protocols (targeted messages), and the MESI state-based protocol.

📌 Definitions & Key Terms

Cache Coherence Problem
In a multiprocessor with private caches, the same memory block may be copied into several caches; a local write can make other copies stale. All processors must observe a consistent value.
Write-Back
Write updates only the local cache; main memory is updated later upon eviction. (Causes stale copies in other caches).
Write-Through
Write updates both cache and main memory. (Main memory is current, but other caches may still hold stale copies).
Snoopy Protocol
Each cache controller continuously watches (snoops) the shared bus for writes to addresses it holds.
Directory Protocol
A central directory tracks which caches hold which memory blocks; targeted messages are sent only to relevant caches.
MESI Protocol
A 4-state write-invalidate snoopy coherence protocol (Modified, Exclusive, Shared, Invalid).

⚠️ The Coherence Problem (Example)

  1. P1 and P2 both read X = 10 (both caches have X = 10).
  2. P1 writes X = 20 to its cache.
  3. P2 reads its cached X and gets 10 (stale value).
✔ Fix: Invalidate or update other cached copies whenever a shared line is modified.

✍️ Write Policies and Coherence

🔹 Key Distinction

  • Write-Back: local cache updated; memory updated later. Other caches may hold stale copies.
  • Write-Through: cache and memory updated together. But other caches may still retain old copies; notification/snooping is still required.
  • Key Distinction: write policy determines when memory is updated; coherence protocol determines which cached copies remain valid.

💻 Software-Based Coherence

🔹 Compiler / OS Analysis

  • Compiler/OS analyzes shared data and marks unsafe data non-cacheable or inserts coherence operations.
  • Advantage: less special hardware.
  • Limitation: conservative static analysis may unnecessarily disable caching (reduces performance).

🔧 Hardware Solutions

📡 Snoopy Protocol

  • Cache controllers watch the bus for writes to addresses they hold.
  • Write-Invalidate: writer invalidates other copies before writing (more common; basis of MESI).
  • Write-Update: writer broadcasts updated data to all caches (more traffic).
  • Assumption: global bus where all communication is visible to all.
  • Limitation: does not scale (broadcast traffic consumes bus bandwidth).

📂 Directory Protocol

  • Central (or distributed) directory tracks which caches hold each memory block.
  • Requests/invalidations sent as point-to-point messages only to relevant caches.
  • Exclusive-Write Sequence: Request → Directory identifies holders → Invalidations sent → Acks received → Exclusive access granted.
  • Advantages: avoids broadcast; scales to large systems.
  • Disadvantages: directory storage overhead; message-management overhead; possible directory contention.

🔄 MESI Protocol (4 States)

State Meaning Memory Other Caches
M (Modified) Valid, locally modified (dirty) Out of date No other valid copies
E (Exclusive) Valid, clean Up to date No other valid copies
S (Shared) Valid, clean Up to date May exist in other caches
I (Invalid) Not valid — May exist elsewhere

🔹 MESI Local Transitions

Reads

  • Read Hit in M/E/S: return local data.
  • Read Miss in I: fetch; enter E (no other copies) or S (others have it).

Writes

  • Write Hit in M: remain M.
  • Write Hit in E: → M without bus invalidation.
  • Write Hit in S: issue invalidate, then → M.
  • Write Miss in I: acquire exclusive ownership, then → M.

🔹 MESI Bus-Snooped Transitions

Another Processor Reads

  • E → S
  • M → S (supply/write-back modified data first)
  • S stays S

Another Processor Requests Ownership

  • E → I
  • S → I
  • M → I (after supplying modified data)

📏 Key Rules

• Only one cache can hold a line in M or E state.
• Several caches can hold a line in S state.
✅ Valid combinations: One M + all I; One E + all I; One or more S + others I; All I.
❌ Invalid combinations: Two M's; M + S; E + S; E + E.
📌 KEY EXAM POINTS
Snoopy is natural for bus-based SMPs (broadcast is easy).
Directory scales better for large systems (targeted messages).
MESI uses 2 status bits per cache line to encode 4 states.
E → M is cheaper than S → M (no invalidation needed).
When another processor reads an M line, the modified data must be made available (owner typically transitions M → S).
