📝 Graphics Processing Unit (GPU) Topic 9

The 1-Sentence Story: A GPU is a specialized, highly parallel processor designed for data-intensive tasks, using hundreds of simple ALUs and a multi-level memory hierarchy (SMs, L2 cache, DRAM) to maximize throughput rather than single-thread latency.

📌 Definitions & Key Terms

GPU
Graphics Processing Unit: a specialized processor built for parallel computation, originally for 3D graphics, now used for AI/ML, HPC, and more.
SM
Streaming Multiprocessor: the core building block of a GPU, containing multiple ALUs, its own instruction scheduler, and a private L1 cache.
Data Parallelism
Applying the same operation to many data elements simultaneously (GPU's primary strength).
Latency Hiding
GPUs switch to other threads while waiting for memory, keeping ALUs busy, rather than reducing memory latency.

⚖️ CPU vs. GPU Structure

Feature CPU GPU
Focus Low latency (single thread) High throughput (many threads)
Control Unit Large, complex Minimal
Cache Large Small
ALUs Few, powerful Hundreds/thousands, simple
Best For Complex branching, sequential code Data-parallel, compute-intensive tasks

🏗️ GPU Architecture Fundamentals

SM → L2 Cache → DRAM

🔹 Memory Hierarchy

  • Streaming Multiprocessors (SMs): multiple SMs per GPU. Each SM has ALUs, instruction schedulers, and private L1 cache.
  • L2 Cache: shared by all SMs. Acts as a middle layer between SMs and DRAM.
  • DRAM: main GPU memory (high bandwidth).
  • Data Flow: SM checks L1 → L2 → DRAM.

🔹 Execution Model

  • SIMD within a core (many ALUs perform the same instruction).
  • Multi-threaded execution on a single core.
  • Goal: maximize overall computing throughput, hide memory latency via thread switching.

📌 KEY EXAM POINTS
GPUs are throughput-oriented; CPUs are latency-oriented.
GPUs hide latency by switching threads, not by reducing memory latency.
SMs are the building blocks; L2 is shared; DRAM is the main memory.
Discrete GPUs are more powerful but consume more energy; integrated GPUs are more power-efficient but less performant.
GPUs excel at "embarrassingly parallel" workloads (same operation on lots of data).
